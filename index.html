Genie Agents & Supervisor Best Practices

Design, CI/CD, observability, and multi-agent operating patterns.

Genie space delivery

  • Use curated tables, clear metric definitions, and strong examples
  • Store prompts, instructions, and benchmark questions in Git
  • Run benchmark regressions before promoting environment changes
  • Use dev, test, and production promotion gates for safer rollout

Supervisor patterns

  • Use Supervisor Agent for multi-domain questions across tools or subagents
  • Write precise tool and subagent descriptions for better routing
  • Apply least-privilege access so users only reach permitted sources
  • Keep examples current and representative of executive workflows
